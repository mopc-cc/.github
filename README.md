# .github

Repositorio especial de la organización. Los archivos que están acá se aplican por defecto a **todos los repositorios** de la organización que no tengan su propia versión.

> ⚠️ Este repositorio es **público** (GitHub lo exige para que los archivos por defecto funcionen). No agregar acá nada interno ni confidencial: nombres de clientes, datos, credenciales, URLs internas.

| Archivo | Para qué sirve |
| --- | --- |
| `PULL_REQUEST_TEMPLATE.md` | Plantilla que aparece al abrir un Pull Request |
| `.github/ISSUE_TEMPLATE/` | Plantillas para reportar errores o pedir mejoras |
| `CONTRIBUTING.md` | Convenciones de trabajo: ramas, commits y revisiones |
| `profile/README.md` | Portada pública de la organización |

Si un repositorio necesita algo distinto, crea su propio archivo con el mismo nombre y ese reemplaza al de acá.
